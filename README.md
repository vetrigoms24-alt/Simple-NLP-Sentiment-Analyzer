# Rule-Based NLP Sentiment Analyzer

A lightweight Python application that performs Natural Language Processing (NLP) and text classification using rule-based sentiment scoring. Developed to build on Python computational concepts learned in IT coursework at Rutgers University.

## Project Background & Learning
Built as an applied Python project to extend concepts practiced in university IT coursework—such as dictionary lookup, tokenization, string manipulation, and list iteration—into practical software applications.

## Features
* **Text Processing:** Parses user-input sentences into clean, lowercase tokens.
* **Sentiment Classification:** Evaluates text against predefined positive and negative token dictionaries to determine overall tone (Positive, Negative, or Neutral).
* **Interactive CLI Loop:** Allows continuous user prompts with automated rule-based decision outputs.

## Tech Stack
* **Language:** Python 3
* **Core Concepts:** Data Structures (Lists, Dictionaries), String Methods, Control Flow, Command-Line Interfaces (CLI)
